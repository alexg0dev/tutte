# Reporting a security issue

If you find a way to read someone else's chats, recover a key without the password or passphrase, or get the model to reveal something [`redact.js`](redact.js) is meant to hide, please tell us privately before posting about it.

Report it through this repository's **Security** tab, under **Report a vulnerability**. Please don't open a public issue.

Include what you did and what you saw. We'll reply on the report.
